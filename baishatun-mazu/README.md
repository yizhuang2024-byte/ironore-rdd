## 製作方式

- **畫面**：`render/lib.js`（元件：廟宇、神轎、頭旗、人物、燈籠、筊杯、煙火、鞭炮、雲、浪、樹…）與 `render/scenes.js`（12 個場景、鏡頭關鍵幀、音效時間點）。全部用 SVG 路徑繪製，沒有使用 AI 生圖。線條用 `pathLength` + dash 做出「邊畫邊出現」；用 feTurbulence 位移濾鏡、每 3 格換一次種子，做出手繪抖動感；物件都有紙色底，可遮住後景；夜景改成深藍底配米金色線條，光源加上漸層光暈；紙紋由 `make_paper.py` 產生，以 multiply 疊加。
- **逐格渲染**：`render/render.js` 以 headless Chromium 每格呼叫 `render(frame)`，等兩次 requestAnimationFrame 確保繪製完成才截圖，再用管線送進 x264，4 段平行渲染後串接。
- **旁白**：`tools/tts.py`，先生成全部 21 句並量秒數，再由 `tools/timeline.py` 算出每個場景長度（句前 1.4s、句間 0.8s、句後 1.6s；片名卡 6.5s、片尾 11s）。
- **配樂與音效**：`tools/mix.py` 全部程式合成——古箏（加按音顫音的撥弦加法合成）、笛子（含笛膜嗡聲與氣聲）、堂鼓、大鑼／小鑼、鈸、木魚；各場景有不同速度與編制（例如起駕與回宮用熱鬧的鑼鼓段、刈火用莊嚴的慢鑼、收尾用抒情笛聲）。音效有海浪、海鷗、筊杯落地、鞭炮、鑼、河水、潑水、倒茶、人群、爐火、封條、煙火、「進喔」吶喊。旁白出現時音樂自動壓低約 10 dB。`tools/loudness.sh` 以增益加限幅器迭代，把整體響度調到 -15 LUFS。
- **品質檢查**：`tools/qa_frames.py` 逐格解碼最終 MP4，檢查空白幀、場景切換以外的突跳、凍結畫面——結果 4732/4732 幀，0 個問題。旁白另外用離線語音辨識（sherpa-onnx Paraformer）回聽，確認發音。
- 重新建置：`KOKORO=<kokoro-multi-lang-v1_0 目錄> tools/build.sh`（需要 Python：numpy scipy soundfile pillow imageio-ffmpeg sherpa-onnx；Node：playwright）。

## 注意：旁白聲音
指定的 VoAI「子墨」在這個雲端環境無法使用：voai.ai／connect.voai.ai 被網路政策擋住，也沒有 API 金鑰。因此旁白改用開源離線 TTS **Kokoro v1.0（sherpa-onnx）中文男聲 `zm_yunjian`**，語速 0.92。若要換回 VoAI：把 21 句旁白依序存成 `audio/vo/00.wav`–`20.wav`，重跑 `tools/tts.py` 的量測步驟（或更新 `durations.json`），再執行 `tools/build.sh`，時間軸、字幕、畫面都會自動依新秒數重排。
為了讓 TTS 讀對音，部分句子另外準備了讀音用的文字（`script.json` 的 `tts` 欄位，例如「筊」→「腳」、「刈火」→「義火」）；畫面字幕仍顯示正確用字。
