# 象棋學堂

一個教中國象棋棋譜與戰術的靜態網站：從棋子走法、記譜法，到殺法戰術與殘局破解，
每個範例都用會動的棋盤逐步演示。使用者也可以自己擺設局面出題，讓別人來破解。

## 開啟方式

純靜態網站，沒有建置步驟，也不依賴任何外部套件或 CDN。

```bash
# 從專案根目錄起一個靜態伺服器
python3 -m http.server 8000
# 然後開啟 http://localhost:8000/chess/
```

直接用瀏覽器開 `chess/index.html` 也可以（腳本都是傳統 script，不受 file:// 的模組限制）。

## 內容

| 分頁 | 內容 |
| --- | --- |
| 棋子走法 | 七種棋子的規則，含蹩馬腿、塞象眼、砲架、過河兵等細節。棋盤上的落點由規則引擎即時算出。 |
| 看懂棋譜 | 中文記譜法的四字規則，搭配一盤「當頭炮對屏風馬」開局逐步演示。 |
| 殺法戰術 | 馬後炮、悶宮、重炮、臥槽馬、鐵門栓、雙將、白臉將、雙車錯共八種殺型。 |
| 殘局挑戰 | 九道由淺入深的排局（1～3 步殺）。使用者在棋盤上實際走子，電腦即時驗算並替黑方應將。 |
| 自己擺棋 | 擺設任意局面、驗算有沒有連將殺、並產生可分享的連結。 |

## 檔案結構

```
chess/
├── index.html
├── css/style.css
├── js/
│   ├── rules.js    規則引擎：走法產生、將軍判斷、中文記譜、連將殺搜尋
│   ├── board.js    棋盤元件：SVG 棋盤 + 絕對定位棋子，換位置時以 CSS transition 產生滑動動畫
│   ├── data.js     教學內容、戰術範例、殘局題庫
│   └── app.js      各分頁的互動邏輯
└── tools/verify.cjs  題庫驗算腳本
```

## 關於正確性

殘局的判定沒有寫死答案，而是由 `rules.js` 的殺法搜尋即時驗算：
使用者走的任何一著，只要仍能維持連續將軍把對方殺死，就算正確，
所以同一題有多種殺法時都能過關；黑方的應著則挑抵抗最久的走法。

題庫本身可以隨時重新驗算：

```bash
node chess/tools/verify.cjs
```

腳本會檢查規則引擎的基本行為，並逐題確認：起始局面合法（將帥在九宮、未輪走的一方沒有被將軍）、
標示的步數確實存在連將殺、主變每一著合法、且主變終局對方確實一步棋也走不出來。

## 已知範圍

殺法搜尋只搜尋「連續將軍」的殺法，這也是絕大多數排局殺法的形式；
需要先走閒著（不將軍的等著）的殺法不在搜尋範圍內，「自己擺棋」的求解器同樣受此限制。
